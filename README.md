# QR Studio

A small Flutter QR code generator app for a mini project.

## Run

1. Install Flutter and make sure `flutter` is available in your PATH.
2. Open this folder in a terminal.
3. Run `flutter pub get`.
4. Run `flutter run`.

## Features

- Generate QR codes for text, websites, email addresses, and phone numbers.
- Live preview while typing.
- Copy generated content to the clipboard.
- Responsive layout for mobile and desktop.
